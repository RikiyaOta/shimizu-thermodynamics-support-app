## 1. 数学的仕様と必要要件

### 1.1 象徴的なピースワイズ関数 $f(x)$
$x > 0$ における定義:
$$
f(x) = \begin{cases} 
\frac{x^3 + x}{4} & (0 < x < 1) \\
x - \frac{1}{2} & (1 \le x < 2) \\
\frac{x^2}{2} - x + \frac{3}{2} & (2 \le x < 3) \\
\frac{x^2}{2} - \frac{3}{2} & (3 \le x) 
\end{cases}
$$

### 1.2 導関数 $f'(x) = p$
$$
f'(x) = \begin{cases} 
\frac{3x^2 + 1}{4} & (0 < x < 1) \quad (\text{範囲: } 0.25 < p < 1) \\
1 & (1 \le x < 2) \quad (\text{一定値: } p = 1) \\
x - 1 & (2 \le x < 3) \quad (\text{範囲: } 1 \le p < 2) \\
x & (3 \le x) \quad (\text{範囲: } p \ge 3) 
\end{cases}
$$

### 1.3 清水テキストの重要な物理的・数学的着眼点
1. **導関数の平坦領域 ($1 \le x < 2$)**:  
   $f'(x) = 1$ で一定です。ルジャンドル変換 $g(p) = xp - f(x)$ において、$x$ を $1 \to 2$ へ動かしても $p = 1$ のまま変化せず、$g(1) = 0.5$ という単一の点に収縮します。これは微分の一意な逆関数が存在しない場合でもルジャンドル変換が定義できることを示します。
2. **導関数の跳躍不連続点 ($x = 3$)**:  
   $f'(x^-) = 2$ かつ $f'(x^+) = 3$ となり、$p \in (2, 3)$ に対応する $x$ は存在しません。幾何学的定義（長方形 $xp$ から $f'(x)$ の下面積 $f(x)$ を引き算する）に従うと、$p \in (2, 3)$ では $g(p) = 3p - 3$ となり、$(2, 3)$ と $(3, 6)$ を直線的に滑らかに繋ぎます。

### 1.4 ルジャンドル変換 $g(p)$ の幾何学的定義
$$g(p) = \text{長方形の面積 }(x \times p) - \int_0^x f'(x') dx' = xp - f(x)$$

## 2. 技術スタックと開発構成

- **ビルドツール**: Vite (TypeScript)
- **パッケージマネージャー**: `pnpm`
- **UIフレームワーク**: React 18 + TypeScript
- **数式描画ライブラリ**: KaTeX (`katex`) - 美しいLaTeX数式表示
- **アイコンライブラリ**: Lucide React (`lucide-react`)
- **スタイリング**: Modern CSS3 / Tailwind CSS (ダークモードデザインシステム)
- **グラフ描画**: HTML5 Canvas API + React カスタムフック (高性能・60fpsリアルタイム幾何領域描画)
- **ビルド成果物**: 完全静的な HTML/CSS/JS 成果物 (`dist/` ディレクトリにビルドされ、任意の静的サーバやGitHub Pagesで動作)

## 4. UIレイアウトとユーザー体験

### 4.1 ヘッダーとコントロール
- **タイトル**: 清水明『熱力学の基礎（第2版）』サポートサイト - ルジャンドル変換の視覚的理解
- **モード切替ボタン**:
  - `[ モードA: 3画面同期ビュー ]`（初期値）
  - `[ モードB: シングル統合詳細 ]`
- **プリセットボタン**: 特殊ポイントへ即座に移動するボタン:
  - `[ x = 0.5 (三次関数部) ]`
  - `[ x = 1.5 (平坦部 p=1) ]`
  - `[ x = 2.5 (直線部) ]`
  - `[ x = 3.0 (不連続ジャンプ部) ]`
  - `[ x = 3.5 (二次関数部) ]`

### 4.2 パラメータ操作部
- $x$ のインタラクティブ・スライダー（範囲 $0.05 \le x \le 4.5$、ステップ $0.01$）。
- $x$ の直接数値入力フィールド。
- グラフ上の直接マウスクリック＆ドラッグ操作。

### 4.3 モードA: 3画面同期ビューレイアウト
1. **グラフ1 ($f(x)$ vs $x$)**:
   - $f(x)$ 曲線と区間境界線の表示。
   - 現在の $x$ における点 $(x, f(x))$ と傾き $p$ の接線を描画。
2. **グラフ2 ($f'(x)$ vs $x$) 【メイン幾何学表示】**:
   - $f'(x)$ ピースワイズ直線・波形を描画。
   - 長方形 $x \times p$ を半透明の枠線で描画。
   - 曲線の下側の $f(x)$ 積分領域（シアン/青）を塗りつぶし。
   - 曲線の上側の $g(p)$ 領域（オレンジ）を塗りつぶし。
3. **グラフ3 ($g(p)$ vs $p$)**:
   - $g(p)$ 変換曲線を描画。
   - 対応する点 $(p, g(p))$ を強調表示し、軌跡を追跡。

### 4.4 モードB: シングル統合詳細レイアウト
- $f'(x)$ を大きく中央に配置したメインキャンバス。表示レイヤーの個別トグルチェックボックス：
  - `[x] 長方形 xp`
  - `[x] 積分領域 f(x)`
  - `[x] 差分領域 g(p)`
- 下部のコンパクト表示エリアにて $g(p)$ の点追跡およびリアルタイム数式・数式数値をステップ解説。

## 6. 検証・テスト計画

1. **数学的正確性の検証**:
   - 境界点 $x=1, 2, 3$ における $f(x)$ の連続性を確認。
   - 境界移行部における $f'(x)$ の値（$x=1 \implies p=1$, $x=2 \implies p=1$, $x=3 \implies p: 2 \to 3$）を確認。
   - 全領域における $g(p) = xp - f(x)$ の計算精度を確認。
2. **ビルドおよび動作検証**:
   - `pnpm build` がエラーなく正常終了し、`dist/` 内に静的ファイルが生成されることを確認。
   - モードA / モードB の切替がスムーズに行われるか確認。
   - スライダー、数値入力、ドラッグ操作、プリセットボタンの動的連動を確認。
   - 画面描画のパフォーマンス（60fps）を確認。
