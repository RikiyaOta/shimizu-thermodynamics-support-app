# 清水明『熱力学の基礎（第2版）』非公式サポートサイト - ルジャンドル変換ビジュアライザ

清水明 著『熱力学の基礎（第2版）』を深めるための、Webブラウザ上で完結するインタラクティブな非公式学習サポートアプリケーションです。

---

## 概要と目的

熱力学においてルジャンドル変換（Legendre Transformation）は、熱力学関数（内部エネルギー $U$、ヘルムホルツ自由エネルギー $F$、ギブス自由エネルギー $G$ 等）の変数変換を理解する上で不可欠な概念です。

通常の数学教材では $g(p) = xp - f(x)$（ただし $p = f'(x)$）と定義されますが、本書では**「 $f'(x)$ のグラフにおける長方形面積 $xp$ から、 $f'(x)$ の下面積（＝ $f(x)$ 自身）を差し引いた残り（上面積）が $g(p)$ である」**という幾何学的な視点から非常に分かりやすく解説されています。

本アプリは、教科書に掲載されている特徴的な区分定義関数（ピースワイズ関数） $f(x)$ を用いて、独立変数 $x$ をマウスやスライダーでリアルタイムに動かしながら、長方形面積と積分領域の移り変わりをグラフィカルに観察・理解できるツールです。

---

## 象徴的ピースワイズ関数 $f(x)$ の仕様

本アプリで扱う関数 $f(x)$ は、熱力学におけるルジャンドル変換の重要な性質（微分の平坦部や不連続ジャンプ）を示す特別な例題です：

1. **区間1 ($0 < x < 1$)**: 三次関数 $f(x) = \frac{x^3+x}{4} \implies f'(x) = \frac{3x^2+1}{4}$
2. **区間2 ($1 \le x < 2$)**: 平坦領域 $f(x) = x - \frac{1}{2} \implies f'(x) = 1.0$ （一定値）  
   * $x$ が $1.0 \to 2.0$ へ動いても $p=1.0$ のままであり、$g(1) = 0.5$ という単一の点に収縮する様子を確認できます。
3. **区間3 ($2 \le x < 3$)**: 一次関数導関数 $f(x) = \frac{x^2}{2} - x + \frac{3}{2} \implies f'(x) = x - 1$
4. **区間4 ($3 \le x$)**: 二次関数 $f(x) = \frac{x^2}{2} - \frac{3}{2} \implies f'(x) = x$  
   * $x=3$ で $f'(x)$ が 2 から 3 へ跳躍不連続を起こします。$p \in (2, 3)$ では $g(p) = 3p - 3$ という直線補間として $g(p)$ 側がつながる挙動を可視化します。

## 主な機能

- **モードA（3画面同期ビュー）**:
  - $f(x)$ vs $x$ (接線付き), $f'(x)$ vs $x$ (幾何学面積ハイライト), $g(p)$ vs $p$ (変換後曲線) の3つのグラフが完全同期してリアルタイム変化。
- **モードB（シングル統合詳細ビュー）**:
  - $f'(x)$ の幾何学グラフを中央大画面で配置。長方形 $xp$、積分領域 $f(x)$（シアン）、ルジャンドル領域 $g(p)$（オレンジ）のレイヤー重ね合わせ表示トグル付き。
- **直感的な操作**:
  - スライダー操作、数値直接入力、グラフ上のクリック＆マウスクリックドラッグに対応。
  - 注目ポイントへのワンタッププリセットボタン（$x = 0.5, 1.5, 2.5, 3.0, 3.5$）。
- **KaTeX 数式ステップ解説**:
  - 現在の $x, f(x), p, g(p)$ の計算過程と、教科書の物理的・数学的着眼点をステップ毎に解説。

## 技術スタック

- **フロントエンド**: React 18, TypeScript, Tailwind CSS
- **ビルドツール**: Vite
- **パッケージマネージャー**: `pnpm`
- **数式描画**: KaTeX (`katex`)
- **アイコン**: Lucide React (`lucide-react`)
- **グラフ描画**: HTML5 Canvas API (High-DPI 60fps リアルタイム描画)
- **配信形式**: 完全な静的Webコンテンツ (`dist/` ディレクトリ。サーバー不要でブラウザ上で完結)

---

## 開発・ビルド手順

### 1. 依存関係のインストール
```bash
pnpm install
```

### 2. 開発サーバーの起動
```bash
pnpm dev
```
ブラウザで `http://localhost:5173` が自動で開きます。

### 3. テストの実行
```bash
pnpm test
```

### 4. プロダクション静的ファイルのビルド
```bash
pnpm build
```
実行後、`dist/` ディレクトリに HTML, CSS, JS が生成されます。この `dist/` フォルダを GitHub Pages や Vercel, Netlify などの任意の静的ホスティングに配置するだけで即座に公開できます。

### 5. ビルド成果物のローカルプレビュー
```bash
pnpm preview
```
