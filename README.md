# 清水明『熱力学の基礎（第2版）』非公式学習サポートポータル

清水明 著『熱力学の基礎（第2版）』（東京大学出版会）の学習を補助・深化させるための、Webブラウザ上で完結するインタラクティブな非公式学習サポート Web アプリケーション群（ポータルサイト）です。

---

## 概要とコンセプト

本書の厳密かつ明快な熱力学の論理体系や幾何学的・物理的直感を、読者が実際にブラウザ上でパラメータを動かしながら視覚的に体感・確認できる動的ビジュアライザを提供します。

- **ポータル構造**: トップページ（学習コンテンツ一覧）から各トピックのインタラクティブツールへシームレスにアクセス可能な拡張型構成。
- **100% ブラウザ完結 (Pure Client-Side Static SPA)**: サーバーとの通信を必要とせず、すべての数値計算・グラフィックス描画・数式表示がクライアント環境で即座に動作。
- **物理・数学的厳密性**: 教科書の記述や定義、幾何学的アスペクト比（1:1 正方形グリッド等）に忠実に準拠。

## 学習コンテンツ

### 1. ルジャンドル変換の視覚的理解 (`/#/legendre`)

熱力学関数の変数変換（内部エネルギー $U$、ヘルムホルツ自由エネルギー $F$、ギブス自由エネルギー $G$ 等）を理解する上で極めて重要な**ルジャンドル変換（Legendre Transformation）**を幾何学的に可視化するツールです。

#### 幾何学的定義と背景
通常の数学教材では $g(p) = xp - f(x)$（ただし $p = f'(x)$）と形式的に導入されがちですが、本書では**「 $f'(x)$ のグラフにおける長方形面積 $xp$ から、 $f'(x)$ の下面積（＝ $f(x)$ 自身）を差し引いた残り（上面積）が $g(p)$ である」**という幾何学的視点 $g(p) = [xp - f(x)](p)$ から明快に定義されます。

#### 象徴的ピースワイズ関数 $f(x)$ の仕様
熱力学におけるルジャンドル変換の重要な性質（微分の平坦部や不連続ジャンプ）を示す教科書掲載の 4 区間関数を完全実装しています：

1. **区間1 ($0 < x < 1$)**: 三次関数 $f(x) = \frac{x^3+x}{4} \implies f'(x) = \frac{3x^2+1}{4}$
2. **区間2 ($1 \le x < 2$)**: 微分平坦領域 $f(x) = x - \frac{1}{2} \implies f'(x) = 1.0$ （一定値）  
   * $x$ が $1.0 \to 2.0$ へ動いても $p=1.0$ のままであり、$g(1) = 0.5$ という単一の点に対応する様子を確認できます。
3. **区間3 ($2 \le x < 3$)**: 一次関数導関数 $f(x) = \frac{x^2}{2} - x + \frac{3}{2} \implies f'(x) = x - 1$
4. **区間4 ($3 \le x$)**: 二次関数 $f(x) = \frac{x^2}{2} - \frac{3}{2} \implies f'(x) = x$  
   * $x=3$ で $f'(x)$ が $2 \to 3$ へ跳躍不連続を起こします。$p \in (2, 3)$ では $g(p) = 3p - 3$ という直線補間として $g(p)$ 側がつながる双対挙動を可視化します。

#### 主な機能
- **リアルタイム連動グラフ**:
  - $f(x)$ vs $x$（接線表示）
  - $f'(x)$ vs $x$（長方形面積 $xp$、下面積 $f(x)$、ルジャンドル領域 $g(p)$ のハイライト）
  - $g(p)$ vs $p$（変換後曲線）
  - $g'(p) = x$ vs $p$（双対軸交換グラフ）
- **直感的な操作性**:
  - マウスドラッグ、スライダー操作、数値直接入力に対応。
  - 特徴的ポイントへのワンタッププリセットボタン（$x = 0.5, 1.5, 2.5, 3.0, 3.5$）。
- **KaTeX 数式ステップ解説**:
  - 現在のパラメータに応じた計算過程と物理的着眼点を KaTeX でリアルタイム解説。

## 開発・ビルド手順

### 1. 依存関係のインストール
```bash
mise exec -- pnpm install
```

### 2. 開発サーバーの起動
```bash
mise exec -- pnpm dev
```

### 3. テストの実行
```bash
mise exec -- pnpm test
```

### 4. プロダクションビルド
```bash
mise exec -- pnpm build
```
ビルド成果物は `dist/` ディレクトリに生成されます。

### 5. ローカルプレビュー
```bash
mise exec -- pnpm preview
```
